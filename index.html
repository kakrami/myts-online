How do I create a Client ID?
  1. Open TeamSnap Applications and sign in.
  2. Create an application and give it a clear name, such as Manager Console.
  3. Set the Redirect URI to exactly https://kakrami.github.io/myts.
  4. Save it, then copy the Client ID / UID into the field above.
